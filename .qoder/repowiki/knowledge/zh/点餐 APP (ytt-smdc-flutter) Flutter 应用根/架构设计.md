根目录通过 pubspec.yaml 集中声明 Flutter/Dart 依赖（Dio、Provider、Fluro、sqflite、dart_amqp 等），由子模块共享；lib/ 下按 pages/mvp/net/routers/util/widgets/res 等职责划分，新模块需实现 routers/IRouterProvider 并在 routers.dart 中统一注册，从而将页面与路由解耦。ci_and_scripts 提供 Windows 端 Flutter Android/iOS 构建与 Codemagic iOS 无签名打包辅助，是构建期唯一编排点。根 README 定义了添加新模块的标准流程：在 lib/pages 创建目录 → 实现 IRouterProvider → 在 routers.dart 注册。
