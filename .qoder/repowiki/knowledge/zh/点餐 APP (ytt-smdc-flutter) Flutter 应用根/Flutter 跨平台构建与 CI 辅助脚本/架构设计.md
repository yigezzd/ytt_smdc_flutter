本模块由一组独立的 PowerShell 脚本与一份 Codemagic 云构建配置组成，按目标平台拆分职责：
- `build_apk.ps1`：在 Windows 上执行 `flutter build apk --release --split-per-abi`，解析 `pubspec.yaml` 中的 `version+buildNumber` 通过 `--dart-define=FULL_VERSION` 注入，并仅保留 arm64-v8a APK 重命名为 `ytt_smdc_flutter_<fullVersion>.apk`。
- `build_ipa.ps1`：处理 Codemagic 产出的 .ipa，自动搜索当前目录 / `build\ios` / 系统 Downloads，复制并重命名为带版本号的 ipa，随后输出 Sideloadly 安装步骤（无需 Mac）。
- `download_flutter.ps1`：从 Google 官方源下载 Flutter SDK 3.41.0，失败后回退到清华镜像站，落盘至 `D:\flutter_sdk.zip`。
- `get_short_path.ps1`：借助 COM `Scripting.FileSystemObject` 将 JDK 长路径转换为短路径（用于兼容某些工具链）。
- `codemagic.yaml`：定义 `ios-test-build` workflow，在 Codemagic macOS runner 上执行 `flutter pub get` → `flutter build ios --release --no-codesign` → 手动 zip 为 Payload 形式的 .ipa，作为 artifacts 输出；该 workflow 配合 `build_ipa.ps1` 实现无 Apple 开发者账号的测试包分发。

依赖方向单向：PowerShell 脚本仅依赖 Flutter CLI、Windows 文件系统与命令行工具；`codemagic.yaml` 是唯一的云 CI 入口，不反向依赖本地脚本。
